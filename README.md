# Swiff Bounty — Website

Official website for **Swiff Bounty**, Breton reggae/hip-hop artist.

## GitHub

- **Repository**: https://github.com/ColinLeverger/swiffbounty
- **Pages**: https://colinleverger.github.io/swiffbounty

## About

Swiff Bounty is a complete artist: singer, songwriter, and performer. His hybrid music blends reggae, hip-hop, and dancehall influences with modern production. His energetic live presence and powerful lyrics position him as one of the standout voices in the French alternative music scene.
